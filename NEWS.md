# zugojson 0.0.0.9000

* Numbers that are not whole are written about five times faster, through
  the shortest-digits code in Goose's standard library. The text written is
  unchanged.

* Initial version: `json_format()`, `json_minify()` and `json_valid()`, with
  a JSON parser and printer written in Goose and compiled to C, and a
  replacement Goose runtime that reports runtime failures as R errors.
